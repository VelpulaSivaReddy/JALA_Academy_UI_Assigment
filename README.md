# Front-End Development Assignments

A collection of practical assignments covering fundamental concepts of Front-End Development.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- AngularJS
- Node.js
- MySQL

## Topics Covered

- **HTML5:** Elements, forms, input types, semantic tags and iframes.
- **CSS3:** Styling, layouts, positioning, animations and responsive design.
- **JavaScript:** Variables, functions, objects, DOM manipulation, events, JSON and cookies.
- **AngularJS:** Controllers, directives, data binding, filters, services, HTTP requests, form validation and routing.
- **Database Integration:** Connecting AngularJS applications with MySQL using Node.js.

## How to Run
1. Clone this repository.
2. Open the project folder in VS Code.
3. Open the required HTML file using Live Server.
4. View the output in your browser.

## Purpose
Practical implementation of front-end technologies through examples and exercises.
